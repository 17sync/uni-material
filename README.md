# Overview

This repository is a collection of course materials, assignments, non-coding lab tasks, notes, books, and project files from my Software Engineering degree. Everything is organized by semester and course to make it easier to find and revisit resources when needed.

I created this archive primarily for personal reference as having a remote data store for relevant course material is very convenient when working with multiple devices, but it may also be helpful to other students looking for study materials, examples, or past coursework. 

The repository covers subjects I have studied as a part of my degree until now and will hopefully be updating and maintaining this repo as I progress myself.

(currently in 4th sem)
